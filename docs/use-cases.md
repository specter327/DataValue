1. Validacion de datos en tiempo de ejecucion (run-time)

Util para evaluar los datos para la entrega a:
- Un proceso
- Una funcion (parametros)
- Un objeto (construccion)
O cualquier otro que requiera datos delimitados o sanitizados.
Como una funcion/metodo/proceso describiendo exactamente los datos que recibe, y los datos que entrega

2. Intercambio de datos con caracteristicas estrictas

La des/serializacion a formato JSON permite el intercambio en comunicacion de los contratos de datos entre dispositivos. Como un servidor enviando a un cliente el formato de dato que debe cumplir cada campo de la solicitud

3. Almacenamiento de datos con caracteristicas estrictas

La des/serializacion a formato JSON permite el almacenamiento y recuperacion de los contratos de datos entre reinicios. Como un proceso que recupera y vuelve a cargar los requirimientos contractuales de sus datos.
